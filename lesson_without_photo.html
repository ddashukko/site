ПЗ №5. Варіант 16 (Вправа 9.1.2, Задача 1)

Завдання: Побудувати двоїсту задачу та показати взаємоспряженість.

Пряма задача:

L = x1 - 2x2 + 3x3 - x4 → max
2x1 - x2 + 2x3 - 3x4 ≤ 5
x1 + 2x2 - x3 + x4 ≤ 3
x1, x2, x3, x4 ≥ 0

Двоїста задача:

Оскільки пряма задача на максимізацію і всі обмеження типу "≤", двоїсті змінні невід'ємні (y1, y2 ≥ 0), а обмеження будуть типу "≥".

F = 5y1 + 3y2 → min
2y1 + y2 ≥ 1
-y1 + 2y2 ≥ -2
2y1 - y2 ≥ 3
-3y1 + y2 ≥ -1
y1, y2 ≥ 0

Взаємоспряженість пар задач (умови доповнювальної нежорсткості):

  • Кожній змінній прямої задачі відповідає обмеження двоїстої:
    x1 ≥ 0 ↔ 2y1 + y2 ≥ 1
    x2 ≥ 0 ↔ -y1 + 2y2 ≥ -2
    x3 ≥ 0 ↔ 2y1 - y2 ≥ 3
    x4 ≥ 0 ↔ -3y1 + y2 ≥ -1
  • Кожному обмеженню прямої задачі відповідає змінна двоїстої:
    2x1 - x2 + 2x3 - 3x4 ≤ 5 ↔ y1 ≥ 0
    x1 + 2x2 - x3 + x4 ≤ 3 ↔ y2 ≥ 0

ПЗ №5. Варіант 16 (Вправа 9.2.2, Задача 3)

Завдання: Дослідити шляхом графічного аналізу двоїстої задачі.

Пряма задача:

L = 2x1 + x2 + 2x3 → min
-x1 + x2 + x3 = 2
x1 - 3x2 - 2x3 = 1
x1, x2, x3 ≥ 0

Двоїста задача:

Оскільки пряма задача на мінімізацію, двоїста — на максимізацію. Обмеження-рівності у прямій задачі означають, що двоїсті змінні y1, y2 вільного знака (не обмежені).

F = 2y1 + y2 → max
-y1 + y2 ≤ 2
y1 - 3y2 ≤ 1
y1 - 2y2 ≤ 2
y1, y2 ∈ R

Графічний аналіз двоїстої задачі:

Запишемо обмеження у вигляді функцій для побудови області:

1) y2 ≤ y1 + 2
2) y2 ≥ (1/3)y1 - 1/3
3) y2 ≥ (1/2)y1 - 1

Область допустимих розв'язків двоїстої задачі не обмежена зверху праворуч. Вектор градієнта цільової функції c = (2; 1) вказує напрямок зростання.
Візьмемо параметричну точку (t, 0.5t). Для t ≥ -2 ця точка лежить всередині допустимої області. Тоді цільова функція F = 2t + 0.5t = 2.5t. При t → +∞ значення F → +∞.

Fmax → +∞
Двоїста задача не обмежена зверху.

Висновок для прямої задачі:

За теоремою двоїстості, якщо двоїста задача не обмежена, то пряма задача не має допустимих розв'язків (несумісна).

Математичне підтвердження (для перевірки):
Додамо рівняння прямої задачі:
(-x1 + x1) + (x2 - 3x2) + (x3 - 2x3) = 2 + 1
-2x2 - x3 = 3
Оскільки за умовою x2, x3 ≥ 0, ліва частина завжди ≤ 0, а права дорівнює 3. Рівність неможлива, допустима множина порожня.
