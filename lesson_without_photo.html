ПЗ №5. Варіант 16 (Впр. 9.1.2, Задача 1)

Пряма задача:

L = x1 - 2x2 + 3x3 - x4 → max
2x1 - x2 + 2x3 - 3x4 ≤ 5
x1 + 2x2 - x3 + x4 ≤ 3
xj ≥ 0, j=1..4

Двоїста задача:

F = 5y1 + 3y2 → min
2y1 + y2 ≥ 1
-y1 + 2y2 ≥ -2
2y1 - y2 ≥ 3
-3y1 + y2 ≥ -1
y1, y2 ≥ 0

Умови доповнювальної нежорсткості (комплементарності):

x1 (2y1 + y2 - 1) = 0
x2 (-y1 + 2y2 + 2) = 0
x3 (2y1 - y2 - 3) = 0
x4 (-3y1 + y2 + 1) = 0

y1 (5 - 2x1 + x2 - 2x3 + 3x4) = 0
y2 (3 - x1 - 2x2 + x3 - x4) = 0

ПЗ №5. Варіант 16 (Впр. 9.2.2, Задача 3)

Пряма задача:

L = 2x1 + x2 + 2x3 → min
-x1 + x2 + x3 = 2
x1 - 3x2 - 2x3 = 1
xj ≥ 0, j=1..3

Двоїста задача:

F = 2y1 + y2 → max
-y1 + y2 ≤ 2         (L1: y2 ≤ y1 + 2)
y1 - 3y2 ≤ 1         (L2: y2 ≥ y1/3 - 1/3)
y1 - 2y2 ≤ 2         (L3: y2 ≥ y1/2 - 1)
y1, y2 ∈ R

Графічний аналіз:

F = 2y1 + y2 → max

1. Допустима область двоїстої задачі (виділена зеленим) необмежена зверху в напрямку вектора-градієнта C = (2; 1).

2. Значення цільової функції зростає безмежно: Fmax → +∞.

Висновок: Оскільки двоїста задача не обмежена зверху, пряма задача несумісна (допустима множина X = ∅).
